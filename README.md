## RSABHK - Test Case

Created for technical test with tight deadline (I created it for 11 hour) for FullStack Developer Position at RSAB Harapan Kita Jakarta. Building with Laravel, Blade, & MySQL.
Feature : 
- Dashboard
- Manage Worker
- Manage Insurance Data
- Manage Service Room Data
- Manage Patient Data
- Manage Patient Registration Data
- Manage Detail Transaction on Patien Registration
- Manage Action Treatment Data
- Multi Role Login (Admin, Worker)

## How to Install
```bash
composer install
```

```bash
php artisan key:generate
```

```bash
# Make sure before you run this command, you have done set your .env file
php artisan migrate
```

```bash
php artisan db:seed
```

```bash
php artisan serve
```
